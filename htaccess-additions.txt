PASTE THIS INTO public_html/.htaccess ON BLUEHOST (do not upload this file itself)
===========================================================================

Why: Bluehost's default rules tell browsers and Cloudflare to keep HTML pages for 2 hours, so a
changed page can take that long to show up. This shortens it to 5 minutes for .html files only.
WordPress pages (PHP) are not affected; the only PHP file it touches is notices.php.

How:
1. In cPanel File Manager, turn on Settings > Show Hidden Files, open public_html and COPY
   .htaccess to .htaccess-before-newsite (a backup you can restore).
2. Edit .htaccess and paste the block below on a NEW LINE AT THE VERY TOP, above
   "# BEGIN WordPress". Do not change anything else and do not put it inside the WordPress or
   Newfold sections (those get rewritten automatically).
3. Save and open https://agatebeachgolf.net/?t=3. If you ever see a 500 error, restore the backup
   copy (rename it back to .htaccess) and tell me.

--------------------------- copy from the next line ---------------------------
# BEGIN Agate Beach static pages
<IfModule mod_expires.c>
  <FilesMatch "\.html$">
    ExpiresActive On
    ExpiresByType text/html "access plus 5 minutes"
  </FilesMatch>
  # notices.php sets its own 5-minute cache; stop the 24-hour default from being added as well.
  <Files "notices.php">
    ExpiresActive Off
  </Files>
</IfModule>
# END Agate Beach static pages
